# 📊 Customer Segmentation using RFM Analysis | Power BI

## 📌 Project Overview

This project focuses on **Customer Segmentation using RFM (Recency, Frequency, Monetary) Analysis** to identify high-value customers and analyze customer purchasing behavior.

The dashboard was built using **Power BI** and **Power Query** by transforming raw transactional data into meaningful business insights through interactive visualizations and customer segmentation.

The project also includes a **Sales Analysis Dashboard** to provide an overall view of sales performance across countries, months, weekdays, and customer behavior.

---

# 📂 Dataset

**Dataset Name:** Online Retail II

The dataset contains one year of transactional data from an online retail store.

### Data Period

**1 December 2010 – 9 December 2011**

---

# 🎯 Project Objectives

- Perform customer segmentation using RFM Analysis.
- Identify high-value and low-value customers.
- Discover revenue contribution by different customer segments.
- Build an interactive Power BI dashboard for business decision making.

# 📊 RFM Methodology

Customers were segmented based on:

### Recency (R)

Number of days since the customer's most recent purchase.

### Frequency (F)

Number of orders placed by each customer.

### Monetary (M)

Total revenue generated by each customer.

Customers were then assigned R, F and M scores and grouped into the following segments:

- Champions
- Loyal Customers
- Can't Lose Them
- At Risk
- Lost Customers
- New Customers
- Others

# 📌 Key Insights

## RFM Analysis

- Average Recency: **93.06 days**
- Average Frequency: **4.27 orders**
- Average Monetary Value: **2.05K**
- Total Champions: **911**

### Customer Orders

- Champions placed the highest number of orders (**10.8K**).
- Others contributed **4.04K** orders.
- Loyal Customers placed **2.13K** orders.
- Lost Customers generated only **0.33K** orders.
- New Customers generated only **0.07K** orders.

### Customer Distribution

- Others represent the largest customer group (**2,339 customers**).
- Champions account for **911 customers**.
- Only **182 customers** are At Risk.
- Only **67 customers** are New Customers.

### Customer Behavior

- Frequency and Monetary show a **positive but weak correlation**, indicating customers who purchase more frequently generally spend more.

### Average Order Value

- At Risk customers have the highest Average Order Value (**26**).
- Champions follow closely with an Average Order Value of **25**.
- New Customers have the lowest Average Order Value (**11**).

### Revenue Contribution

- Champions generated **5.36M (64.57%)** of total revenue.
- Others generated **1.53M (18.44%)**.
- Loyal Customers generated **0.75M (9.02%)**.

### Top Customers

Top 10 highest revenue customers include:

14646, 18102, 17450, 16446, 14911, 12415, 14156, 17511, 16029, 12346

Among them:

- 7 Champions
- 1 Loyal Customer
- 2 Others

---

## Sales Analysis

- Total Sales: **8.91M**
- Total Customers: **4.34K**
- Total Orders: **19K**
- Average Order Value: **22.40**

### Country Analysis

- United Kingdom generated **82.04%** of total revenue (**7.31M**).
- Netherlands ranked second (**0.29M**).
- EIRE ranked third (**0.27M**).

### Monthly Sales

- November recorded the highest sales and customer count.
- December, October and September followed.
- February had fewer customers than January but generated higher revenue.

### Weekday Analysis

- Thursday generated the highest revenue (**1.82M**).
- Tuesday ranked second (**1.59M**).
- Sunday generated only **0.76M**.
- No sales were recorded on Saturday, suggesting the store may have been closed.
